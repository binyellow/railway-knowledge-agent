# 接触网检修规程

接触网检修必须在停电天窗内进行，严格执行"停电、验电、挂接地线"三步骤，作业前确认双侧来电方向均已封线。

定位器检修：定位器坡度标准值为1:10至1:6，坡度过大或过小都会加剧接触线磨耗或造成脱弓事故。定位管、定位线夹不得有裂纹、松动。

拉出值与导高：直线区段拉出值一般为±300mm，曲线区段按超高计算确定；接触线导高误差不得超过设计值的±30mm。中锚处导高应等于相邻跨距导高。

检修周期：接触网全面检查每6个月一次，分段检测（导高、拉出值）每3个月一次，步行巡视每周一次，夜间巡视每月一次。隧道内接触网每季度专项检查一次。

绝缘部件：绝缘子脏污季节（秋冬季）必须增加清扫频次，爬电痕迹超过规定标准立即更换。凡涉及接触网带电距离不足的隐患，按一级隐患管理，24小时内处理。

作业资质：接触网作业人员必须持有接触网工证及高压电工证，高空作业必须系安全带并设专人监护。
