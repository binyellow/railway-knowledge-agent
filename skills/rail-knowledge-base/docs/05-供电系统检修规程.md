# 供电系统检修规程

地铁供电系统包含110kV主变电所、35kV环网、1500V/750V直流牵引供电及400V低压动力照明系统。

35kV环网检修：电缆头测温每季度一次，红外测温发现温差异常（相间温差超过8K）安排停电检查。环网电缆交叉互联箱、接地箱每年开箱检查一次。

变压器检修：主变压器每半年进行一次油色谱分析，乙炔含量超过规定值（5ppm）必须查明原因。干式变压器绕组温度、风机启动值每季度校验一次。

继电保护：继电保护装置定值每两年全面校验一次，保护装置本体试验每年一次。凡涉及定值变更，必须凭整定单执行，执行后双人复核。

直流牵引系统：接触网（轨）供电分区停电作业必须执行工作票制度，验电、挂地线、挂牌上锁（LOTO）一个不能少。直流快速断路器大修每5年一次。

杂散电流防护：排流柜每季度检查一次，轨电位限制器每年试验一次。杂散电流腐蚀监测数据每月分析，超标区段安排专项治理。

倒闸作业：所有倒闸操作必须执行操作票，一人操作一人监护，操作前唱票复诵，严禁约时停送电。
