# 应急抢修管理规程

设备故障实行分级管理：一级故障（中断行车或影响行车安全）、二级故障（功能部分丧失，可维持限速运行）、三级故障（不影响行车，纳入常规维修）。

响应时限：一级故障抢修人员必须在15分钟内出动，30分钟内到达现场（车辆段及基地内20分钟）；二级故障2小时内到场处理；三级故障24小时内处置完毕。

抢修组织：一级故障由调度长（或值班调度）统一指挥，相关专业抢修班组长为现场指挥。跨专业故障（如接触网与车辆冲突）由调度指定牵头专业，其余专业配合，禁止相互推诿。

抢修天窗：行车中断时区间封锁即为抢修天窗，抢修负责人凭调度命令进入。抢修中需要临时变更作业范围的，事后必须补充完善记录。

恢复行车的条件：故障设备修复后必须经过功能试验；无法彻底修复但可临时恢复行车的，须由现场指挥评估风险，采取限速、切除冗余等措施，报调度同意后先恢复行车，再安排彻底修复。

复盘要求：一级故障24小时内出快报，7日内完成复盘分析，明确责任、暴露问题、整改措施闭环。同类故障重复发生的提级管理。
