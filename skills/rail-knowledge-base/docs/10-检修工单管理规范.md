# 检修工单管理规范

检修作业实行工单闭环管理，无工单不作业（抢修可先作业后补单，24小时内补录）。

工单类别：计划工单（来源于检修周期计划）、故障工单（来源于故障报警或人工报修）、巡检工单（来源于日常巡检发现）。

工单必备字段：工单编号（WO-日期-序号）、线路、位置、设备类型与编号、检修类别（日常检修/故障修/专项修/巡检）、优先级、风险等级、安全措施、资质要求、作业负责人、计划时间窗、作业描述。

派发与接单：调度（或班组长）派发工单至作业负责人，负责人接单后确认作业条件。优先级为紧急的工单直接推送至班组值班电话。

闭环要求：作业完成后填写实际工时、消耗材料、处理结果、遗留问题，验收人签字确认。故障工单必须关联故障现象与原因分类（便于可靠性统计）。带病运行的设备必须在工单中注明监控措施与彻底处理时限。

超期管理：工单超期未完成自动升级提醒。紧急工单超期2小时、高优先级超期24小时未闭环的，推送给部门主管。月度工单闭环率考核指标不低于98%，故障工单平均处置时长纳入班组绩效。
