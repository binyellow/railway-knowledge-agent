# 轨道检修规程

轨道几何尺寸管理是线路检修的核心。轨道静态几何尺寸容许偏差管理值按作业验收、经常保养、临时补修三级管理。

轨距：标准轨距1435mm，正线验收作业容许偏差为+4mm、-2mm，经常保养容许偏差+6mm、-3mm。轨距变化率不超过1‰。

水平与三角坑：水平容许偏差验收标准4mm，三角坑（扭曲）容许偏差验收标准4mm，且基长6.25m范围内检查。三角坑是导致车辆脱轨的主要隐患，超限必须立即处理。

钢轨探伤周期：正线钢轨探伤每30天一个周期，年通过总重超过5000万吨的区段缩短为20天。道岔区段探伤周期为正线的二分之一。发现轨头内部伤损达到轻伤标准时加强观测，达到重伤标准立即更换或处理。

钢轨磨耗：总磨耗超过规定值（正线50kg/m轨总磨耗16mm）时必须更换。波浪形磨耗谷深超过0.4mm安排打磨。

线路巡检：正线线路每日巡检一次，重点区段（道岔、桥隧、路基病害处）加强检查。曲线地段每季度检测一次轨道几何尺寸，仪器检测每半年全线覆盖一次。
