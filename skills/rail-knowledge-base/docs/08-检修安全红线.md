# 检修作业安全红线

以下红线条款为强制性规定，违反者一律停止作业、离岗培训，并按安全奖惩办法处理。

一、严禁无计划、无命令进入轨行区作业。未取得调度命令或车站登记，任何人不得进入正线轨行区。

二、严禁未停电、未验电、未挂接地线检修接触网及牵引供电设备。验电必须使用合格验电器，接地线先接接地端后接导体端。

三、严禁在道岔作业时不断开安全接点。防止道岔中途转换挤伤人员。

四、严禁天窗点外进行影响行车的作业。抢修必须经行调批准并落实防护。

五、严禁无证操作特种设备及从事特殊工种作业。接触网工、信号工、电工必须持证上岗。

六、严禁登高作业不系安全带。2米以上高空作业必须双人作业。

七、严禁防护员脱岗或兼职其他工作。防护中断时作业必须立即停止。

八、严禁甩掉联锁、信号设备强行开放信号。联锁试验未完成的设备不得投入使用。

九、严禁带电插拔插件、带负荷拉闸。电器检修必须断电挂牌。

十、严禁酒后上岗、疲劳作业。连续作业超过规定时间必须轮换休息。
