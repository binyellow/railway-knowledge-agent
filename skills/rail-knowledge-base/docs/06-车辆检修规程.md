# 车辆检修规程

城市轨道交通车辆实行日检、双周检、月修、定修、架修、大修六级检修体制。

日检：每日回库后进行，检查内容包括受电弓状态、转向架、制动系统、车门、车下悬吊件、客室照明广播。列车出库前必须完成日检并确认合格。

双周检与月修：双周检重点检查走行部、制动系统性能；月修增加牵引系统、辅助电源系统功能测试。月修中必须测试制动缸活塞行程，超限调整。

定修：每运行10万公里或每年一次（先到为准），进行架车检查，转向架部件探伤，更换易损件。

架修：每运行50万公里或5年，列车解体至大部件级，转向架、车钩、制动装置全部解体检修。

大修：每运行100万公里或10年，整车全面解体，车体矫正、大部件更换、全车电缆检查更新。

检修安全：库内作业必须确认接触网已停电并挂好接地线，设置防溜措施，作业端悬挂警示牌。车顶作业必须两人以上，一人作业一人监护。升弓作业前确认网压正常。
