# 天窗修管理制度

天窗是指列车运行图中不安排列车运行、为施工检修预留的时间段。凡进入轨行区、影响行车的作业必须纳入天窗管理。

天窗分类：天窗分为日常维修天窗（夜间，一般每日不少于2小时，通常00:30-04:30）、施工天窗（周末或节假日延长）、抢修天窗（故障紧急情况下随时申请）。

申请流程：日常维修天窗由作业部门提前3天提出申请，明确作业内容、范围、人数、防护措施；施工调度审核批准后，作业负责人凭调度命令进入。

销点制度：作业结束后，作业负责人必须确认人员、机具、材料全部撤出，设备恢复正常，向施工调度销点。严禁未销点放行列车。

防护员制度：所有轨行区作业必须设置专职防护员，防护员与车站（或调度）保持通讯畅通，列车接近时提前通知下道。防护员不得兼任其他工作。

天窗利用率考核：各专业月度天窗利用率不低于85%，虚报天窗、点内未完成既定作业的纳入考核。连续两个月利用率低于60%的部门须专项说明原因并整改。
