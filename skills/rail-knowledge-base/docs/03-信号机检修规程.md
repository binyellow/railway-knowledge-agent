# 信号机检修规程

信号机是行车指挥的核心设备，检修作业必须在天窗点内进行，作业前联系信号楼（行车调度）登记要点。

灯丝断丝报警：主灯丝断丝必须立即更换，并在48小时内完成副灯丝检查。LED信号机单灯故障率超过规定值时整灯更换。机构门密封条老化进水必须整治，防止雨水造成电路短路。

信号机显示距离：正常显示距离不得小于200米（曲线区段按设计规定）。色灯信号机的灯位排列、颜色必须符合规定，灯压符合标准范围。

检修周期：信号机日常巡视每日一次，集中检修每年一次，机构内部清扫检查每半年一次。信号电缆径路每月巡查一次，发现施工扰动立即防护并上报。

联锁试验：涉及联锁关系的检修作业完成后，必须进行联锁试验，试验项目包括信号机开放、关闭、灯丝转换、进路办理与取消，全部合格后方可销点。

电子设备防雷：雷雨季节前必须完成信号设备防雷元件检查，接地电阻不得超过规定值（一般不大于10欧姆，计算机联锁机房不大于4欧姆）。
