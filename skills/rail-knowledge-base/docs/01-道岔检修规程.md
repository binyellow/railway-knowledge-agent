# 道岔检修规程

道岔是轨道系统中直接关系行车安全的关键设备，必须严格执行检修标准。

转辙机检修：动作电流不得超过额定值，ZD6型转辙机动作电流正常范围为1.2A~1.8A，超过2.2A必须停用检查。道岔缺口监测系统缺口值标准为1.5mm~2.5mm，缺口报警值设定为3mm。转换时间超过规定值（S700K型13秒）应立即上报。

道岔检修作业安全要求：作业前必须断开转辙机安全接点并加锁，防止道岔中途转换造成人员伤害。作业时必须加装钩锁器。尖轨与基本轨间隙超过规定值时必须更换或整治。

道岔巡检周期：正线道岔每日巡检一次，每月检查一次转换设备特性，每季度进行一次全面检修。车辆段道岔每两日巡检一次。故障道岔实行故障修，修复后必须连续三次转换试验正常方可开通使用。

工电联整：道岔问题涉及工务（轨道几何）与电务（转换设备）两个专业时，必须实施工电联整作业，联合验收。
